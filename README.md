# 幸福时刻生成器

一款简约而温馨的应用，随机生成幸福事件，为您的日常生活增添一抹惊喜。

## 项目简介

幸福时刻生成器是一个基于 UniApp 开发的跨平台应用，旨在通过随机生成简单而美好的幸福事件（如听一首感动的音乐、去公园散步等），为用户提供愉悦的体验。每次点击，系统都会从预设的事件列表中随机选择一个尚未展示过的事件，并配以相应的图片，确保每次体验都充满新鲜感。

## 主要功能

### 随机生成幸福事件
- 预设多种幸福事件，每个事件都独一无二
- 智能记忆已生成事件，确保不会重复
- 每个事件都配有精美图片，增强视觉体验

### 历史记录查看
- 记录所有已生成的幸福事件
- 可随时查看历史记录，回顾美好时刻
- 详细展示事件内容和生成时间

### 重置功能
- 一键重置已生成的事件列表
- 重新开始随机生成过程，体验更多惊喜

## 技术特点

- **高性能**：响应迅速，操作流畅，图片加载快速
- **简约设计**：界面简洁美观，操作直观易用
- **跨平台兼容**：支持 iOS 和 Android 系统，适配多种设备屏幕

## 使用指南

1. 打开应用，进入主界面
2. 点击"换一个幸福时刻"按钮，生成随机事件
3. 查看事件描述和配图
4. 点击"查看历史记录"可浏览之前生成的事件
5. 需要重新开始时，点击"重置列表"
